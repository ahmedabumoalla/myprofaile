# منصة أعمال رقمية

نسخة محلية عربية متجاوبة تحافظ على الفيديو، الحركة، الأقسام، الألوان، والخطوط في الصفحة المرجعية.

تتضمن صفحة `work.html` معرض المشاريع التفاعلي الكامل بتخطيط البطاقات المروحي ونافذة تفاصيل كل مشروع.

## التشغيل

```powershell
npm start
```

ثم افتح `http://127.0.0.1:4175`.

## إضافة المشاريع

بطاقات قسم «أفكار تحوّلت إلى مشاريع تنمو» موجودة داخل `index.html` تحت العنصر ذي المعرّف `projects`. كل بطاقة تحتوي منطقتين فارغتين:

- `project-slot__media` للصورة أو الفيديو.
- `project-slot__content` لاسم المشروع ووصفه وأرقامه.

يمكن تكرار عنصر `project-slot` لإضافة بطاقات أخرى مع الاحتفاظ بنفس طريقة العرض المتناوبة.
